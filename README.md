# Campus Canteen

A responsive food ordering web application built for college campuses. Students can browse the menu, search and filter food items, add them to a cart, and place orders — all from the browser.

##  Live Demo

[View Live Site](https://sreejaboini92.github.io/campus-canteen)

## Features

- Browse popular menu items with food images
- Search food items in real time
- Filter by category — Meals, Snacks, Breakfast
- Add items to cart with quantity tracking
- Remove individual items or clear the entire cart
- Live cart total calculation
- Animated cart badge counter
- Checkout confirmation
- Contact form for feedback
- Fully responsive design

##  Built With

- HTML5
- CSS3 (Flexbox, CSS Grid, transitions)
- Vanilla JavaScript (DOM manipulation, event handling)

##  Getting Started

To run this project locally:

1. Clone the repository
   ```bash
   git clone https://github.com/sreejaboini92/campus-canteen.git
   ```
2. Open `index.html` in your browser

No installations or dependencies required.
